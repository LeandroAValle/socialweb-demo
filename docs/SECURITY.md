# Privacidade e segurança da demonstração

- Este repositório contém somente código novo e dados sintéticos. Nenhum cadastro, documento, credencial, cadeia de conexão ou histórico do sistema operacional original deve ser adicionado.
- O snapshot estático foi criado para ser público. Nunca substitua o arquivo por uma exportação de produção.
- A API é somente leitura e usa a base sintética em memória. Não há conexão a banco ou autenticação porque não existe dado privado nesta demonstração.
- A interface cria elementos de texto com `textContent`, sem inserir conteúdo dos dados como HTML executável.
- Este projeto não implementa controle de acesso, auditoria ou regras de elegibilidade para uso operacional. Não deve ser usado com dados reais.

Para reportar uma questão do demo, abra uma issue sem incluir informações pessoais ou sensíveis.
