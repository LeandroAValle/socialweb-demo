# Registro de decisões

| Decisão | Motivo | Consequência |
| --- | --- | --- |
| Criar um repositório público novo | O sistema operacional original pode conter dados pessoais, documentos e configurações | Separação clara entre portfólio e produção; nenhum histórico privado é publicado |
| Gerar dados com semente fixa | Facilitar reprodução e revisão dos indicadores | O dataset não varia a cada acesso |
| Derivar todas as métricas dos registros | Evitar números decorativos inconsistentes | Soma dos territórios pode ser confrontada com o total |
| Entregar API local e snapshot estático | Mostrar backend sem hospedar serviço público | O painel online é de leitura e funciona no GitHub Pages |
| Usar JavaScript sem framework no site | Reduzir dependências e facilitar inspeção | Componentização é simples; escopo é uma página demonstrativa |
| Não implementar elegibilidade automática | Regras assistenciais exigem contexto e validação institucional | Nenhuma decisão real pode ser inferida dos dados do demo |

## Próximos passos possíveis

Em um produto real: autenticação e autorização por perfil, auditoria, critérios aprovados pelo órgão responsável, governança e retenção de dados, observabilidade, testes de contrato e integração com uma base protegida. Esses itens não são simulados como prontos nesta demonstração.
