SOBRE O PROJETO

Uma demonstração, construída com responsabilidade.

Este projeto independente apresenta conceitos de gestão social por meio de uma API de leitura em C#/.NET, indicadores reconciliáveis e uma interface web. Os dados são sintéticos, gerados por uma semente fixa. As métricas são ilustrativas e não representam desempenho real de serviços públicos.
